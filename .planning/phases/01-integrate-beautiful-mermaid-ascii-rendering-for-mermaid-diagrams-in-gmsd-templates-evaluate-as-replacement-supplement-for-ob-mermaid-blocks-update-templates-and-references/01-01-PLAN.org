<task type="auto">
  <name>Task 1: Install beautiful-mermaid and create render script</name>
  <files>package.json, get-my-shit-done/bin/render-mermaid.cjs</files>
  <action>
1. Install beautiful-mermaid as a dependency:
   npm install beautiful-mermaid

2. Create get-my-shit-done/bin/render-mermaid.cjs as a CJS module that:
   - Exports a renderWithinWidth(source, maxWidth = 120) function
   - Uses renderMermaidASCII from beautiful-mermaid with options:
     useAscii: false (Unicode box-drawing for readability)
     paddingY: 1
     boxBorderPadding: 1
   - Implements paddingX fallback: tries paddingX 2, then 1, then 0
   - Returns { ascii, paddingX, width } on success, null if all paddings exceed maxWidth
   - When run directly (require.main === module), reads Mermaid source from:
     a) File argument (node render-mermaid.cjs diagram.mmd)
     b) Stdin (echo "flowchart LR ..." | node render-mermaid.cjs)
   - Prints rendered ASCII to stdout; exits 1 if rendering fails or exceeds width
   - Prints max line width to stderr for diagnostics

Note: useAscii: false is counterintuitive -- false means USE Unicode (prettier).
The API option name is inverted from expectations.
  </action>
  <verify>
    <automated>node get-my-shit-done/bin/render-mermaid.cjs <<< "flowchart LR\n    A --> B" | head -5</automated>
  </verify>
  <done>Script renders a simple flowchart to stdout. Unicode box-drawing characters visible. Exit code 0.</done>
</task>
