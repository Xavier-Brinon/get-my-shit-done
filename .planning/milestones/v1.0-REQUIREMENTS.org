* Requirements: GMSD Diataxis Integration

** v1.0 Requirements

Requirements for Diataxis documentation framework integration.

*** Classification

- [X] *CLASS-01*: Diataxis condensed reference document exists in =references/=
  with quadrant definitions, writing rules, and anti-patterns for each quadrant
- [X] *CLASS-02*: Every deliverable template (40+) has a Diataxis quadrant
  classification in its metadata or documentation header
- [X] *CLASS-03*: Every org-generating agent (7) has a =<diataxis_style>= tag
  with quadrant-specific writing guidance matching its output templates

*** Gap Analysis

- [X] *GAPS-01*: Formal audit document maps every existing template to a Diataxis
  quadrant and identifies underserved quadrants
- [X] *GAPS-02*: New tutorial template(s) exist for learning-oriented deliverables
  (guided experiences for project onboarding)
- [X] *GAPS-03*: New how-to template(s) exist for task-oriented deliverables
  (step-by-step guides for common GMSD workflows)

*** Internal Docs

- [X] *DOCS-01*: USER-GUIDE.org is split into separate Diataxis-aligned documents
  (tutorial, how-to, reference, explanation)
- [X] *DOCS-02*: Files in =references/= directory are classified by Diataxis
  quadrant and reorganized accordingly
- [X] *DOCS-03*: README.org sections are aligned with Diataxis (tutorial-like
  content separated from reference-like content)

** Future Requirements

Deferred to future milestone. Tracked but not in current roadmap.

*** Tooling

- *TOOL-01*: Automated Diataxis compliance linting for generated documents
- *TOOL-02*: =/gmsd:diataxis-audit= command for on-demand quadrant coverage reporting

*** Ecosystem

- *ECO-01*: Non-org-generating agents (plan-checker, integration-checker, debugger)
  aware of Diataxis when reviewing docs
- *ECO-02*: Diataxis quadrant visible in =/gmsd:progress= output

** Out of Scope

Explicitly excluded. Documented to prevent scope creep.

#+CAPTION: Out of scope items
| Feature                                         | Reason                                            |
|-------------------------------------------------+---------------------------------------------------|
| Restructure =.planning/= dirs by quadrant       | Adds user-facing complexity, low ROI vs classification |
| Upstream GSD integration                        | GMSD-only enhancement, fork divergence is intentional |
| Diataxis for non-doc artifacts (code, commits)  | Over-application of framework                     |
