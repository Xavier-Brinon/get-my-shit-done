<context>
The user uses Emacs and cares about org-mode conventions. This started when they noticed CONTEXT.org used bold-text metadata instead of proper org keywords. They asked to apply the same pattern to ALL documentation, not just context.org.

The pattern is mechanical: find `*Key:* value` or `**Key:** value` at document level, convert to `#+key: value` before the first heading. Section-level bold text in lists stays as-is.

Agent files are trickier — the `**Status:**` patterns are in output format specs that tell agents what to emit. These need the same conversion but may affect agent behavior if agents pattern-match on the format.
</context>
