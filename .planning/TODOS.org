** TODO [#C] Fix #+begin_src json to #+begin_src js in org docs :docs:
:PROPERTIES:
:created: [2026-03-02 Mon]
:files: docs/reference.org, README.org
:END:

*** Problem
Some org-mode source blocks use #+begin_src json for JSON content, but Emacs org-mode uses 'js' (or 'javascript') as the language identifier for JSON syntax highlighting — there is no built-in 'json' major mode in standard Emacs org-babel. Using #+begin_src js provides correct syntax highlighting in Emacs.

*** Solution
Search all org files for #+begin_src json and replace with #+begin_src js. Check docs/, references/, and templates/ directories.
