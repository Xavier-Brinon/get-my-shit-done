* GMSD (Get My Shit Done)

** What This Is

A customised fork of Get Shit Done (GSD) — a meta-prompting, context engineering, and spec-driven development system for Claude Code. GMSD reshapes GSD to fit a specific workflow: Emacs/Org-mode as the documentation format, Architecture Decision Records baked into the planning process, and a "learn software architecture" lens on the existing spec-driven development system.

** Core Value

Every document GMSD produces — both its own internal docs and the deliverables it generates for user projects — follows a principled documentation framework so users always find the right type of doc for their need.

*** Out of Scope

Explicit boundaries. Includes reasoning to prevent re-adding.

- Restructuring =.planning/= directory layout by quadrant — adds complexity for users navigating phase dirs, low ROI vs classification
- Automated Diataxis compliance linting — premature; get the framework integrated first, then consider tooling
- Upstream GSD Diataxis integration — this is a GMSD-only enhancement

** Context

- The fork conversion (GSD → GMSD) is complete: 128/128 tests passing across 8 phases
- 40+ org-mode templates generate deliverable docs in =.planning/= for user projects
- 11 agent definitions, 45 commands, 43 workflows define system behavior
- 7 agents already have =<org_style>= tags referencing the condensed org styleguide
- The existing =docs/USER-GUIDE.org= mixes tutorial, how-to, reference, and explanation content
- Diataxis framework (https://diataxis.fr/) defines 4 documentation quadrants:
  - *Tutorials* — learning-oriented, practical, guided experiences
  - *How-to guides* — task-oriented, goal-focused, for competent users
  - *Reference* — information-oriented, austere description, mirrors code structure
  - *Explanation* — understanding-oriented, context and background, the "why"

** Constraints

- *Format*: All new docs in org-mode (=.org=) per project convention
- *Backward compatibility*: Existing =.planning/= directory structure must not change for user projects
- *Agent prompts*: Changes to agent =.md= files must preserve existing =<org_style>= and =<architecture_learning>= tags
- *Tests*: 128 existing tests must continue to pass
