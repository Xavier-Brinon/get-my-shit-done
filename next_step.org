* Next Steps

** Phase 3: Gap Filling (Next)

Phase 3 addresses the gaps identified in the audit. Two requirements drive the
work:

*** Priority 1: Tutorial Template (=GAPS-02= --- Critical)

Create =templates/tutorial.org= --- a structured, success-guaranteed walkthrough
for new GMSD users.

- *What it should deliver:* A guided exercise that takes a beginner through one
  complete GMSD workflow cycle (discuss → plan → execute)
- *Suggested scope:* "Your First GMSD Phase"
- *Key constraint:* Tutorial is for /learning/, not for /getting things done/ ---
  steps are chosen to build understanding, not for efficiency
- *Structural model:* =user-setup.org= (step-by-step, goal-oriented) but adapted
  for a learning context

*** Priority 2: How-to Template (=GAPS-03= --- Low Coverage)

Create =templates/howto.org= --- a general-purpose template for documenting
repeatable multi-step procedures.

- *What it should deliver:* A reusable template for any operational procedure
  (workflow steps, runbook entries, deployment guides)
- *Current gap:* =user-setup.org= is the only how-to template and is scoped
  exclusively to external service configuration
- *Structural model:* =user-setup.org= with the "external service" framing
  removed and the goal/steps/verification structure made generic

*** Priority 3: Explanation Assessment (Deferred)

Evaluate whether the single explanation template (=project.org=) is sufficient.
The gap is real but lower urgency because explanatory content can be embedded in
ADRs (=adr.org= secondary: explanation) and research docs (=research.org=
secondary: explanation). Consider as Phase 4 scope.

** Phase 4: Internal Docs (Future)
